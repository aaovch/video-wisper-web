Два исключённых источника: `longsword-a:14` в коллекции `noname` и

область поиска. Историческая оценка **67/84** сохранена; если отдельно считать только
допустимые в области источники, доступность составляет **67/82**. Это другой знаменатель,
а не улучшение поиска. Неразрешённых ожиданий внутри области — 15.

## Воспроизведение и защита от неверного измерения

Из корня сайта в PowerShell:

```powershell
$env:SOURCE_LINKS_DIAGNOSE='1'
node node_modules/vitest/vitest.mjs run scripts/search-enrichment/source-links-quality.test.ts
Remove-Item Env:SOURCE_LINKS_DIAGNOSE
```

Передача `limit=120` сама по себе не раскрывает 120 смысловых кандидатов: обычный поиск
дополнительно ограничен 16 результатами (8 внутри записи). Поэтому диагностический запрос
временно задаёт `VITE_SEARCH_CANDIDATE_LIMIT=120`, затем возвращает обычный режим до следующего
сценария. Исходная первая пятёрка всегда измеряется с обычным лимитом. Флаг не включается
в приложении. Первоначальный промежуточный вывод об отсутствии 14 источников на глубине 120
был неверен из-за внутреннего лимита; исправленный результат — девять.

Обычный тест продолжает проверять все 42 минимальных порога v2, наличие ожидаемых глав
в индексе и отсутствие ссылок за пределы области. Диагностический артефакт пишется только
при явном флаге. Проверки качества, runtime-областей и валидатора связей прошли: три теста.
UI и production-код не менялись, повторная сборка для изменения диагностического теста не нужна.

## Следующий эксперимент

Приоритет — вопросы о чувстве соединения без зрения (`noname-16`): два ожидаемых источника
не попадают в первую пятёрку даже внутри своей коллекции; увеличение лимита показывает
только один из них на месте 32. Далее — распознавание ответа и темп монитора (`p-multi-7`)
и доведение атаки партнёром (`expanded-multi-1`, `source-link-confirm-4`).

Проверять представление этих глав в поисковых карточках и конкурирующие результаты.
Это гипотеза о недостаточном представлении условий и целей упражнения, а не доказанная
причина. Новые карточки сначала готовить по полным источникам, затем сравнивать с прежними
на всех принятых регрессиях; текущие раскрытые вопросы не называть новым holdout.
Простое увеличение лимита и добавление новых связей не объявлять решением этих провалов.
