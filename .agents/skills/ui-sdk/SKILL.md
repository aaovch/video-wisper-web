# UI SDK в архиве

Пути указаны от корня проекта. Справочники соответствуют версиям из lockfile.

- Для публичных страниц используй компоненты из отдельных точек входа `@ui-sdk/svelte`. Индекс документации — `node_modules/@ui-sdk/svelte/docs/llms.txt`.
- Для HTML из `server/` используй `@ui-sdk/web`. Индекс — `node_modules/@ui-sdk/web/docs/llms.txt`. Модуль `server/forms-client.js` дополняет серверную форму после загрузки. У полей сохраняй имена и значения POST и рабочий HTML для подачи без JavaScript.
- Первоисточник рекомендаций и тематические справочники поставляются в `node_modules/@ui-sdk/core/skills/ui-sdk/`. Выбирай страницу используемого компонента в документации соответствующего адаптера.
- Общие токены обеих тем хранятся в `src/lib/styles/tokens.css`. Серверные формы получают их через `server/form-styles.mjs`. Локальные команды и браузерные сценарии описаны в `docs/ui-sdk.md`.
