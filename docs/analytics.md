# Статистика Video Wisper

Сбор: `https://video-wisper.goatcounter.com`, официальный `https://gc.zgo.at/count.js`.
Сайт отправляет одно открытие на изменение pathname; поиск, query и hash не создают
дополнительных посещений. Рабочий сбор разрешён только на `aaovch.github.io`,
локальная разработка и production preview исключены. GoatCounter применяет своё
правило sessions (до 8 часов), поэтому показатель называется посещением страницы,
а не уникальным человеком или запуском видео.

## Подключение выгрузки

1. Подтвердить email аккаунта GoatCounter.
2. В настройках аккаунта пользователя, раздел API, создать токен с единственным
   правом **Read statistics** и доступом только к **video-wisper.goatcounter.com**.
   Не включать Record pageviews, Update sites или Export индивидуальных данных.
3. Сохранить токен в GitHub repository secret `GOATCOUNTER_API_TOKEN` для
   `aaovch/video-wisper-web`. Не отправлять его в чат, не сохранять в исходниках
   или переменных с префиксом `VITE_`.
4. После разрешённой пользователем публикации запустить Deploy to GitHub Pages.
   Workflow запрашивает агрегаты, включая все страницы пагинации, и генерирует
   `static/analytics/summary.json`. Ежедневное обновление — 03:23 UTC.

Тот же экспорт локально: установить `GOATCOUNTER_API_TOKEN` в окружении процесса
и вызвать `npm run analytics:export`. `BASE_PATH` по умолчанию `/video-wisper-web`;
для локального сборочного URL без base использовать пустое значение. Начало учёта
по умолчанию `2026-10-03`, переопределение — `GOATCOUNTER_START_DATE`.
Запрос заканчивается на последнем полном часе. Дни и начало периода соответствуют
часовому поясу аккаунта **Asia/Qyzylorda (UTC+5)**; экспорт проверяет настройку через
API и останавливается при её изменении. Текущий день может быть неполным.

Публичный файл содержит только slug, общий счётчик и дневные счётчики материалов
публичного каталога. Изолированные и скрытые коллекции не экспортируются.
Источники переходов, география, имена посетителей, API-токен и другие детали
не входят в файл; полный кабинет GoatCounter остаётся закрытым.
Если экспорт ошибается, workflow останавливается до публикации. Частичная выборка
никогда не публикуется. При отсутствии выгрузки интерфейс показывает отсутствие
данных, а не нулевые значения. Данные старше 48 часов помечаются как устаревшие.

## Старые счётчики

После публикации Page Views API больше не получает новые посещения от сайта.
Перед переходом `npm run analytics:backup-legacy` читает `/views` для всех отчётов
и общего счётчика, без вызовов `/track`. Ошибка любого счётчика прерывает перенос:
неподтверждённые данные не заменяются нулями.

Полная локальная копия 155 отчётов сохранена в родительской папке
`data/analytics-migration/2026-10-03-legacy-all.json`; рабочая копия —
`.codex/analytics/legacy-all.json`. Она включает скрытые материалы и не публикуется.
Версионируемый `src/lib/data/legacy-analytics.json` — данные переноса 130 публичных
материалов, общий счётчик и время начала/окончания снимка. Это постоянный источник
исторических значений; ежедневный workflow его не перезаписывает.

История доступна на вкладке в отдельной сортируемой колонке «Ранее», отдельном
итоге «До перехода» и CSV. Она не зависит от выбранного периода и не складывается
с GoatCounter. Дневную историю из общего счётчика восстановить нельзя.
Публичные счётчики на страницах и в footer читают сохранённый снимок без зависимости
от старого API. Для скрытых материалов прежнее чтение остаётся резервным источником.
Выгрузка не генерирует посещений. Страница `/stats/` показывает все материалы
доступного каталога, поиск, фильтры, сортировку, дневной график и CSV.
Видеоаналитика не включена: посещение страницы не доказывает воспроизведение.

## Проверка

`npm run check`, `npm test`, `npm run build`, `git diff --check`.
Профильные тесты: `npx vitest run src/lib/analytics.test.ts src/lib/goatcounter.test.ts scripts/export-analytics.test.ts scripts/export-legacy-analytics.test.ts`.
На опубликованном сайте проверить один переход на отчёт и переход по таймкоду:
второй не должен отправлять новое открытие. Проверять отправку в отдельном тестовом
аккаунте/потоке; не накручивать production для доказательства работы.

API-контракт: https://www.goatcounter.com/help/api и https://www.goatcounter.com/api.json.
