# Поиск по альтернативным названиям техник

По умолчанию включён ограниченный словарный fallback для пяти проверенных пресетов: цорнхау, мецано, шайтельхау, винден, длинное острие / posta longa. Источник — алиасы и ASR-варианты канонического HEMA-словаря. Компактный `hema-search-presets.json` воспроизводимо формируется тем же импортёром, что и полный снимок; notes и expands_to в браузер не передаются.

## Поведение

Точный поиск и поиск по началу слова сохраняют приоритет. Если они не нашли результат и весь запрос совпал с известным названием, поиск проверяет альтернативные написания до нечёткого исправления опечатки. Возвращаемый исходный заголовок или фрагмент обязан содержать полное альтернативное название. Несколько написаний одного названия не суммируют бонусы. Совпадение помечается «связано по смыслу», не как точная цитата введённого пользователем текста. Ограничения записи, коллекции и зоны сохраняются. Строгие exact API не расширяются.

Произвольные вопросы этим правилом не расширяются. Свойства пресета не превращаются в синонимы. Большинство пресетов пока исключено: например, «окно» в aliases стойки posta di finestra обнаруживает постороннюю главу об интерфейсах; его нельзя переносить в общий поиск без контекста. Исходный HEMA-словарь при этом не изменён.

## Измерение

Шесть фиксированных запросов (`scheitelhau`, `scheitel hau`, `winden`, `виндунг`, `posta longa`, `постолонга`) проверены внутри исходной записи, реальной публичной коллекции и архива. Нужные главы выбраны из существующих источников. Сравнивается одна и та же сборка индекса, с флагом выключено/включено.

**Нужная глава в топ-5: 0/18 → 16/18.** Это тест названий с заведомо существующим источником, а не общий показатель качества или независимый пользовательский набор. Полные выдачи: [technique-alias-results.json](technique-alias-results.json). Тест проверяет принадлежность области и отсутствие потери прежних попаданий.

Две оставшиеся проверки относятся к выбранной главе про posta longa в архиве: для латинского запроса уже есть точные совпадения в других источниках и они сохраняют приоритет; для ASR-варианта выбранная глава шестая. Другие релевантные главы возможны, поэтому эти промахи не означают полностью бесполезную выдачу.

Регрессионное сравнение с сохранённым baseline: 228 сценариев основного фехтовального набора и 68 сценариев сабли/баклера — порядок выдачи, тип совпадения и расширение области совпали полностью. Ответ про обход защиты после батмана остался первым в архиве. Проблема ложных ответов на вымышленные вопросы этим изменением не исправлена.

```powershell
node node_modules/vitest/vitest.mjs run scripts/search-enrichment/technique-search.test.ts
```

Для отключения при сборке: `$env:VITE_SEARCH_TECHNIQUE_ALIASES='0'`; затем `npm run build`. После сравнения удалить переменную. При обычной сборке функция включена. Расширенное ранжирование глав из предыдущего эксперимента по-прежнему выключено.
