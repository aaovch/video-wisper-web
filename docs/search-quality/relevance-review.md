# Проверка релевантности по источникам — ревизия 1

Перечитаны пять вопросов расширенного пилота, соответствующие главы, конспект и конкретные упражнения. Зафиксированы 17 оценок с цитатами, путями внутри исходного JSON и хешами источников. Старый `pilot-expanded.json`, его оценки и результаты экспериментов сохранены без изменений.

Это небольшая разметка одним автором, а не независимая человеческая оценка всего архива. Неразмеченные результаты остаются неизвестными, а не автоматически неверными. Проверяется доступ к подтверждённому источнику из выдачи, не полнота показанного короткого сниппета.

## Что исправлено в методе оценки

1. **Нужная информация отделена от числа источников.** Вопрос о продолжении после проигрыша соединения не требует одновременно найти сексту и винден. Глава «Ответ на проигранное соединение» уже отвечает на него. Уступающий винден оставлен как условный дополнительный пример при давлении защиты, а не обязательная вторая глава.
2. **Один источник может покрывать несколько частей вопроса.** Конспект «Стойка и работа ног» содержит и проверку опоры при шагах, и смену ведущей ноги. Его допустимо считать альтернативой паре глав, если именно он найден.
3. **Упражнение определяется по пункту и времени.** В разделе «Упражнения семинара» много разных упражнений. Для игры «ниндзя и самурай» допустим пункт на 4822,24 секунде; прыжки на 528,89 или связка dritto на 3703,02 не становятся ответом из-за общего заголовка.
4. **Связанный материал не равен полному ответу.** Общая глава о правильной адаптации не объясняет конкретно ошибку недоведённого удара; частичные и связанные источники отмечаются отдельно.

## Повторная оценка той же выдачи

| Вопрос / область | Доля старых ожидаемых глав | Покрытие проверенных частей вопроса |
|---|---:|---:|
| Ошибки завершения атаки / архив | 0 | 0 |
| Продолжение после проигрыша соединения / архив | 1/2 | 1 |
| Опора при шагах и смене ноги с баклером / архив | 1/2 | 1/2 |
| Подготовленные решения и распознавание угрозы / архив | 1/2 | 1/2 |
| Игра на вызов удара в ноги / архив | 0 | 0 |
| Та же игра / запись | 0 | 0 |

**Это изменение оценки, не прирост поиска.** Алгоритм, индекс и карточки не менялись. Альтернативные источники разрешены только по проверенному содержанию; они не обязательно попали в выдачу. В частности, для игры поиск внутри записи вернул другие упражнения, а не нужный пункт.

Старые потери от перестановки и разбиения запросов не отменены. Полностью перепроверять их по новой модели до расширения разметки нельзя: ревизия охватывает только эти пять вопросов.

## Выявленные ограничения

- UI группирует упражнения по общему заголовку, поэтому разные пункты могут скрываться друг за другом. На разобранном вопросе об игре нужного пункта не было уже в сырой выдаче: одна правка группировки этот промах не устранит. Группировку в этом этапе не меняли.
- Условия игры в исходной главе богаче краткой карточки: удар ниже колена без силы, роли участников, зачёт входа только при успешном выходе без попадания. Эти детали — обоснованный кандидат для следующей ревизии карточки, но не добавлены ради подгонки данного вопроса.
- Требуется расширить аудит остальных составных вопросов и альтернативных конспектов. Нельзя переносить единственную поправку оценки на весь корпус или объявлять неизвестные результаты нерелевантными.

## Артефакты и воспроизведение

Ревизия: `scripts/search-enrichment/relevance-reviewed-v1.json`, SHA-256 рядом. Оригинальные оценки вложены для сопоставления; цитаты и текущие исходники проверяются тестами. Замена источника требует новой ревизии либо явного пересмотра, а не молчаливой подмены контрольных сумм.

[Результаты](relevance-review-v1.json) содержат хеш индекса, захваченной выдачи и разметки, покрытые/недостающие части вопроса, неизвестные результаты и конкретные таймкоды.

```powershell
node scripts/search-enrichment/freeze-relevance-review.mjs --dry-run
$env:RELEVANCE_REVIEW='1'
node node_modules/vitest/vitest.mjs run scripts/search-enrichment/relevance-review.test.ts --pool=threads --maxWorkers=1 --no-file-parallelism
Remove-Item Env:RELEVANCE_REVIEW
node scripts/search-enrichment/evaluate-relevance-review.mjs
node node_modules/vitest/vitest.mjs run scripts/search-enrichment/relevance-judgments.test.ts
```

Следующий пакет: расширить эту проверку на остальные составные вопросы, затем подготовить отдельный кандидат карточек с подтверждёнными условиями и проверить его на новых формулировках и прежних регрессиях. Основной скилл и публикация не изменены.

Продолжение: [ревизия v2 и проверка кандидата условий](relevance-review-v2.md) охватывает все 12 составных вопросов. Эта ревизия v1 сохранена без изменения своих оценок.
