# NoName: соединение и австрийская сабля

8 сентября 2026: добавлены 200 проверенных карточек для десяти записей. Теперь целиком покрыты
секции «Меч Пети» (6 записей, 116 глав) и «Сабля Саши» (5 записей, 109 глав) коллекции `noname`.
Первая запись по мечу уже имела 25 карточек. Общий фехтовальный охват — 434 главы в 29 записях.
Лекции Турина и кинезио этой коллекции в пакет не входят. Изменены поисковые sidecar и обязательность
их проверки; исходные тексты, нумерация, таймкоды и состав коллекций сохранены.

Карточки составлены после чтения всех глав этих двух серий, с цитатой для каждого поля.
Два прежних австрийских кандидата (40 глав) проверены повторно как часть расширения покрытия:
их старый нулевой результат остаётся в `austrian-batch.md`, он не объявлен новым приростом.
Генерация идёт при обработке агентом, сайт использует готовый статический индекс.

## Составные и неподдержанные вопросы

Четыре составных запроса проверены в коллекции и общем архиве. Добавление карточек не изменило
сырую полноту источников в top 5. Один запрос требует уточнения самой оценки: `noname-15`
сравнивает ответы после первой защиты на разных дистанциях, но глава 14 уже содержит сравнение
обеих дистанций; глава 15 только раскрывает ближнюю. Отсутствие обеих глав не доказывает неполноту
ответа. Этот дефект оценки описан отдельно, замороженные результаты не переписаны.

Для трёх остальных составных вопросов проблема сохраняется: только одна из шести выдач содержит
обе требуемые главы. Ни новый автоматический подбор, ни обещание полного ответа не включены.
Прежние неудачные способы расширения и разбиения запроса не возвращались в рабочий алгоритм.

Два неподдержанных вопроса касаются личной статистики и оценки вчерашнего спарринга. Поиск возвращает
связанные материалы, во всех шести случаях `matchKind=semantic`; они не содержат запрошенных личных
фактов. Для одного вопроса число связанных результатов коллекции выросло 11→12. Это не засчитывается
как найденный ответ и не считается доказанным улучшением отрицательных примеров.

## Постоянная защита

Все десять записей получили `search_cards_required: true`. Обычный тест проверяет полноту обеих
секций по текущему составу коллекции, включая будущие добавления. 29 успешных новых сценариев
(28 из нового набора и восстановленный прежний вопрос) добавлены к 27 предыдущим: теперь 56
сценариев проверяются обычным `npm test` с исходной цитатой, хешем и изоляцией области.

Полный `qa-report` прошёл: данные, индекс, type-check, 74 web-теста и production build.
Семь исследовательских тестов штатно пропущены обычным запуском; сравнения выше выполнены отдельно.
Предупреждение `SOURCE_STEM_LEGACY` у старого отчёта по мечу сохранено, к карточкам не относится.
Общий аудит: 30 complete, 129 optional missing, ни одного partial/stale/invalid; одна complete-запись
Podlodka не входит в фехтовальные числа.

Браузер production preview: вопрос про убранный на плечо меч показывает соответствующую главу
первой в NoName и внутри записи; переход ведёт в четвёртое занятие, `#ch-10`, `t=3403` (56:42 в подписи).
В общем каталоге вопрос об ошибке девятой защиты показывает общую механику этой защиты вторым
результатом, но специально размеченный разбор ошибки не попал в первую пятёрку. Этот случай
не был задним числом засчитан успешным по близкой главе.
Публикация не выполнялась. Рабочая процедура следующего пакета: [workflow.md](workflow.md).
