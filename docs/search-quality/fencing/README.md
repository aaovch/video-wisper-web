# Поиск по фехтовальным темам и коллекциям

2026-09-06. Фокус проверки перенесён с AI и биоэнергетики на технику, тактику и упражнения HEMA.

Продолжение: [сравнение четырёх вариантов ранжирования](ranking.md), включая новые вопросы по сабле и мечу с баклером. Комбинированный вариант улучшил основной набор, но не включён по умолчанию из-за потери конкретного ответа в архиве на новых вопросах.

В индекс добавлены 55 контекстов и 55 вопросов для всех глав трёх записей: «Преднамеренные и экспромтные действия» (11), «Укол по центральной линии» (19), первого занятия по соединению в лагере NoName (25). Дополнения зафиксированы **до** составления нового набора запросов. Запись по мечу и баклеру оставлена без новых дополнений как контроль конкуренции результатов. Уже существующие дополнения по AI и биоэнергетике сохранены одинаковыми в обоих прогонах.

## Метод

32 исходных вопроса по четырём записям: бытовые описания ошибки, выбор упражнения, терминология, точные названия глав. Для каждого добавлена детерминированная опечатка: всего 64 формулировки. Это 32 связанных семейства, не 64 независимых наблюдения. Вопросы и цитаты: `scripts/search-enrichment/fencing-cases.json`.

Запускается настоящий `searchScoped` на полном индексе, сначала без трёх новых sidecar, затем с ними. Проверяются запись, каждая реальная публичная коллекция записи, главный каталог, весь публичный архив, цепочка расширения из записи и цепочка расширения со страницы коллекции. Повторы одной главы удаляются. Лимиты поиска соответствуют интерфейсу: 30 в каталоге/архиве, 120 в scoped-поиске. Сайт показывает первые пять результатов.

У NoName `isolated: true`: UI-цепочка не включает архив. При расширении из записи в коллекцию исходная запись исключается из списка соседей. Для остальных коллекций моделируется разрешённое расширение на архив. Для любого результата автоматически проверяется принадлежность выбранной области. Закрытые коллекции не разблокируются.

Дополнительно четыре заведомо вымышленных запроса проверяются по архиву и четырём коллекциям. Наличие чужой выдачи считается ложным совпадением, а не найденным ответом.

Метрики отражают попадание **ожидаемой главы**, а не просто нужной записи. Разметка неполная: сходная глава из соседней записи тоже может оказаться полезной. Автор дополнений и проверочных вопросов — один Codex; это исследовательский набор, не независимый human holdout. Вопросы не копировались из расширений; веса и тексты после результатов не подгонялись.

## Наблюдения

Итог: **436 сценариев в каждом из двух прогонов**. Ниже нужная глава в первых пяти результатах; у каждой коллекции 8 исходных вопросов и 8 вариантов с опечаткой. Строгая область и UI-цепочка в этом наборе дали одинаковые показатели.

| Коллекция | До → после / 16 |
|---|---:|
| Лекции и семинары Овчинникова Александра | 6 → 7 |
| Golden Falcon Astana | 6 → 7 |
| Лагерь Владивосток | 11 → 14 |
| NoName, фехтовальный лагерь 2026 | 10 → 10 |
| Меч и Баклер, NoName — контроль без обогащения | 12 → 12 |

По всему публичному архиву: 27 → 34 из 64 формулировок в первых пяти; внутри записи: 52 → 56 из 64. Ухудшений позиции ожидаемой главы в измеренных сценариях нет. Три из четырёх вымышленных запросов по-прежнему дают чужие результаты в архиве и каждой из четырёх проверенных коллекций. Это не устранённая проблема.

Наиболее заметный выигрыш дал конкретный технический материал по уколу во «Владивостоке». Вопрос «Остриё гуляет мимо цели. Как проверить положение ведущей руки?» начал находить нужную главу на третьем месте; вариант с опечаткой тоже. Вопрос о том, как перестать дёргаться на движения соперника, поднял «Око фехтовальщика» на третье место в коллекции Овчинникова и на второе в Golden Falcon.

Сложнее остаются описания принятия решений и тактической ситуации:

- «Сначала узнаёшь атаку, затем выбираешь знакомую защиту» поднимает категорию **преднамеренных** действий вместо преднамеренно-экспромтных. Это реальная смысловая ошибка, а не другое название подходящей главы.
- «Сильнее давлю на меч, но попадаем друг в друга» не поднимает ожидаемое объяснение различия между выигрышем рычага и открытой безопасной линией.
- Тактильное упражнение без зрительного контроля смешивается с соседними материалами о геометрии контакта.
- Контрольная запись по мечу и баклеру всё ещё плохо ищется по описанию укола вблизи и вопросу о начале ремизы внутри ответа соперника.

Семь предметных суждений с точными цитатами сохранены в `scripts/search-enrichment/fencing-pooled.json`; их источники проверяются обычным тестом. Они не меняют исходные qrels и не улучшают показатели задним числом.

Одна подтверждённая особенность ранжирования: `search-core.ts::signalMultiplier` рассчитывает покрытие запроса по исходному заголовку и сниппету. Новые формулировки помогают извлечь главу, но совпадения с ними не участвуют в этой части оценки. Это возможное объяснение ограниченного выигрыша, не доказанная единственная причина промахов.

Следующий эксперимент стоит направить на различение фехтовальных ситуаций и категорий, а также обозначений вроде «захват 4»/«четвёртый захват» и «защита 6»/«секста». Массовое добавление похожих вопросов без новой оценки пока не обосновано.

## Повторный запуск

```powershell
npm run test:search-fencing
```

Команда выполняет оба прогона, проверяет парность задач и возвращает обычный обогащённый индекс даже после ошибки теста. Локальные полные выдачи: `.codex/search-fencing/before.json`, `after.json`. Версионируемая сводка с изменившимися позициями: [results.json](results.json). Отдельно различаются `collection:` (строго внутри) и `collection-flow:` (как на странице с возможным расширением).

Команда завершается ошибкой, если обогащение снижает суммарный Hit@5 хотя бы в одной группе или увеличивает число ложных совпадений. Этот парный контроль не заменяет независимые новые вопросы: общая ошибка обеих версий может остаться незамеченной.

Проверки: оба прогона по 436 сценариев прошли, 41 обычный тест прошёл, type-check без ошибок/предупреждений, production build успешен. В браузере подтверждены третьи позиции «Две ошибки наведения» во Владивостоке и «Проблема учеников и „Око“» в лекциях Овчинникова, с исходными сниппетами и таймкодами. Ошибок консоли не обнаружено. Мобильное устройство и медленная сеть не проверялись.

Проверка касается выбранных тем и не означает полного аудита всех записей пяти коллекций. Не добавлены расширения для сабли, катаны и всех оставшихся тренировок. Модель при запросе пользователя не запускается. Публикация не выполнялась.
