# Копирование доступа из админки

У каждого сохранённого пароля на `/admin/` есть кнопка «Скопировать доступ».
Она копирует три строки: название материала, абсолютную ссылку и пароль.
Если у группы несколько действующих паролей, у каждого своя кнопка.

- Общий пароль коллекции ведёт на её страницу.
- Пароль одной записи ведёт прямо на запись, сохраняя коллекцию в `?from=`.
- Пароль пакета из нескольких записей ведёт на содержащую их коллекцию.

После копирования появляется сообщение об успехе. Если браузер запрещает
доступ к буферу обмена, открывается и выделяется тот же текст для ручного
копирования. Пароль не добавляется в URL. Копирование не изменяет ключи,
разрешения или сессии. Страница доступна только владельцу и не кешируется.

Проверки:

```text
node --test server/password-share-test.mjs
```
