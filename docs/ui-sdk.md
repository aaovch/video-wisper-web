# UI SDK в HEMA-архиве

## Источник и установка

- Репозиторий: https://github.com/vercel-labs/ui, изученная ревизия `56a7c9394d62907fa35b6d1c3d324e15397f18a2`.
- Установлены `@ui-sdk/core`, `@ui-sdk/svelte` и `@ui-sdk/web` версии `0.1.0-beta.10`, зафиксированы в lockfile. Это beta API; обновлять вместе и повторять браузерные проверки.
- Проектный навык в `.agents/skills/ui-sdk` указывает на справочники из установленного пакета и документацию адаптеров Svelte и Web Components.
- Минимальная версия Svelte в package.json поднята до `^5.33.0` согласно требованиям адаптера; фактически установленная версия осталась `5.56.3`.

SDK предоставляет поведение и доступность компонентов, а не готовый дизайн. Использованы отдельные entry points и собственные стили архива, добавлен CSS-слой `ui-sdk`. Стандартная тема `web.css` не подключена.

## Что применяется

`SearchFilters.svelte` и новый `SearchFilterPopover.svelte`: отдельный Popover на каждую группу, штатные trigger/content/close, Input для поиска вариантов, Checkbox для выбора и Button для очистки. SDK управляет размещением, закрытием, ARIA и возвратом фокуса. Состояние выбора продолжает поступать в существующий контроллер поиска; одновременно открыта одна группа. Сохранены чипы и возврат фокуса после удаления последнего чипа.

`ArchiveKeyDialog.svelte`: Dialog, Title, Description, Close, Field, Input и Button. Сохранён внешний метод `open(collection)`, проверка ключа и переход к материалам. SDK удерживает фокус внутри окна и возвращает его к вызвавшему элементу. Поле очищается при закрытии; `data-agent-secret` исключает его значение из снимков и результатов агентского API.

Агентский мост создаётся только в тестовом стенде. Он проверяет доступность операций через SDK, но не добавляет на публичный сайт глобальный API или WebMCP. Доступ к материалам по-прежнему проверяет сервер.

## Локальная проверка

Node 24, Google Chrome. `npm run test:ui-sdk` сначала выполняет `node server/build.mjs`, затем запускает Playwright. Два локальных сервера создаются и останавливаются автоматически: архив на 4197 с базой доступа в памяти и стенд реальных компонентов на 4198. Тестовый ключ `sdk-test` существует только в этой базе в памяти, для группы `hema-theory`.

```powershell
npm run check
npm run qa-report
npm run test:ui-sdk
# Отдельная статическая сборка после генерации индекса:
npm run build:site
# Оставить серверную сборку открытой для ручной проверки:
node scripts/ui-sdk/serve.mjs
```
